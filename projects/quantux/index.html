quantum + tuxedo

Quantux

The tuxedo cat from the Griffiths quantum-mechanics cover, rebuilt as a custom Codex Terminal Pet for compatible terminals on macOS and Linux.

source on GitHub · install

Why I made it

I liked the tuxedo cat on the cover of David J. Griffiths and Darrell F. Schroeter's Introduction to Quantum Mechanics, third edition. It made me want a quiet version of that character living in my terminal while I studied and worked.

The name compresses that origin into one word: quantum + tuxedo = Quantux.

The cover is shown here in a small format for identification and commentary and links to the publisher's page. Quantux intentionally follows its cat; rights in the original cover artwork remain with their respective holder(s).

What is included

  • An installable Codex custom-pet manifest and transparent 8 × 9 sprite sheet.
  • Seventy-two frames for idle, running, waving, waiting, grooming, and other states.
  • A preview GIF plus the source keyframes and Pillow-based rebuild script.
  • No Swift application, account, API key, background service, or macOS-only state.
  • Usable with compatible terminal image protocols such as Kitty graphics or Sixel.

One character, one package

Quantux is deliberately narrow: the repository contains one Codex Pet package and one visual identity, the Griffiths-cover-cat design shown here.

Install it locally through Codex's custom-pet directory and select Quantux · Griffiths Cat from /pets. Keeping the package terminal-oriented also makes a later move to Ubuntu and Kitty practical.
