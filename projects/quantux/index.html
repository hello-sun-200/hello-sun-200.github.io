Quantux

A small, native macOS companion: part tuxedo cat, part interface experiment, and named for the quantum-mechanics book that started it.

source on GitHub · art provenance

Why I made it

I liked the tuxedo cat on the cover of David J. Griffiths and Darrell F. Schroeter's Introduction to Quantum Mechanics, third edition. It made me want a quiet version of that character living on my own desktop while I studied and worked.

The name compresses that origin into one word: quantum + tuxedo = Quantux.

The cover is shown here in a small format for identification and commentary and links to the publisher's page. It is not included in the Quantux source repository or offered under the project's licenses; rights in the cover remain with their respective holder(s).

What it does

  • Walks, rests, and perches around the current application's window edges.
  • Responds to petting, dragging, treats, do-not-disturb mode, and a growing bond.
  • Provides short multi-turn conversations through a user-supplied DeepSeek API key.
  • Keeps the API key in macOS Keychain and stores pet state locally.
  • Uses native Swift, AppKit, SwiftUI, Accessibility APIs, and procedural sound.

Public and private art

My private prototype keeps the early cover-inspired artwork for personal use. The public repository uses a separately generated black-and-white tuxedo cat with yellow eyes, based on two documented CC0 photographs. Public project art is released under CC0; the code and documentation use the MIT License.

Quantux currently targets the Apple Silicon Mac, macOS 26, and Xcode 26 setup I use myself. It is open source, but it is deliberately a personal-device-first project rather than a promise of broad compatibility.
